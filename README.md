# سرورق | Sarvaragh

> کتاب بعدی‌ات را کشف کن.

نسخه منتشرشده: [sarvaragh.vercel.app](https://sarvaragh.vercel.app)

سرورق یک کتابخانه دیجیتال فارسی و راست‌به‌چپ برای **کشف، جستجو و ذخیره کتاب‌ها** است. داده‌ها از API عمومی [Open Library](https://openlibrary.org/developers/api) می‌آیند و عنوان‌ها، نام نویسندگان، موضوعات و معرفی کتاب‌ها به فارسی نمایش داده می‌شوند. پروژه فقط برای کشف و معرفی کتاب است و فروشگاه، پرداخت، کتاب‌خوان آنلاین، ثبت‌نام یا بک‌اند اختصاصی ندارد.

## امکانات

- **صفحه اصلی (`/`)**:
  - هیرو با «دیوار جلد» متحرک از کتاب‌های پرخواننده، جستجوی بزرگ و پیشنهادهای موضوعی.
  - ویترین زبانه‌دار (Tabs + Carousel): محبوب‌ترین‌ها، بالاترین امتیاز و کلاسیک‌های محبوب، با معیار شفاف برای هر فهرست.
  - کارت‌های **۱۶ موضوع** با جلدهای واقعی بادبزنی و تعداد کتاب‌ها از کاتالوگ:
    - ادبیات، داستان و رمان، فلسفه، روان‌شناسی، تاریخ، علوم، کسب‌وکار، برنامه‌نویسی و فناوری
    - شعر، زندگی‌نامه و خاطرات، کودک و نوجوان، فانتزی، علمی‌تخیلی، معمایی و جنایی، رشد فردی و اقتصاد
  - جلدهای صفحه اصلی همراه پروژه ارسال می‌شوند (`public/covers/`)، پس بدون معطلی و حتی با اینترنت کند نمایش داده می‌شوند.
  - ویترین‌ها (دیوار جلد، قفسه‌ها، کارت موضوع‌ها و کتاب‌های مشابه) فقط کتاب‌های دارای جلد را نشان می‌دهند. کتاب بدون جلد با کتاب بعدی فهرست جایگزین می‌شود.
  - نویسندگان پرخواننده: فقط نویسندگانی که عکس دارند (۱۲ نفر). عکس‌ها همراه پروژه در `public/authors/` هستند و نویسنده بی‌عکس با نفر بعدی جایگزین می‌شود.
  - بخش «در قفسه‌ها قدم بزن» با «نمایش بیشتر».
- **کشف کتاب‌ها (`/discover`)**:
  - جستجو در همه فیلدها، فقط عنوان یا فقط نویسنده، با Debounce و لغو درخواست قبلی.
  - **جستجوی فارسی**: عبارت فارسی برای جستجو به انگلیسی ترجمه می‌شود (مثلاً «غرور و تعصب» → Pride and Prejudice) و این موضوع زیر نتایج اعلام می‌شود.
  - فیلتر ترکیبی موضوع، زبان، بازه سال و **محبوبیت** (همه / ۱۰۰+ / ۱٬۰۰۰+ خواننده).
  - «فقط کتاب‌های دارای جلد» به‌طور پیش‌فرض روشن است. با خاموش کردن آن (`covers=all` در URL) همه کتاب‌ها نمایش داده می‌شوند و کتاب‌های بی‌جلد یک جلد طراحی‌شده می‌گیرند.
  - مرتب‌سازی: مرتبط‌ترین، **محبوب‌ترین**، **بالاترین امتیاز**، جدیدترین، قدیمی‌ترین، بیشترین ویرایش و الفبایی.
  - نمایش شبکه‌ای یا فهرستی، صفحه‌بندی، چیپ‌های فیلتر فعال و اشتراک پیوند. همه وضعیت در URL است.
  - در موبایل، فیلترها داخل Sheet باز می‌شوند.
- **جستجوی سریع (Ctrl+K یا `/`)**: پنجره Command با نتایج زنده و جلد کتاب‌ها.
- **جزئیات کتاب (`/books/[id]`)**:
  - عنوان فارسی همراه عنوان اصلی، نویسندگان با عکس، امتیاز ستاره‌ای و آمار خوانندگان Open Library.
  - جلد سه‌بعدی، پس‌زمینه محو از رنگ جلد و انیمیشن جابه‌جایی جلد از کارت به صفحه (View Transitions).
  - معرفی کتاب در دو زبانه «متن اصلی» (پیش‌فرض، بی‌درنگ نمایش داده می‌شود) و «ترجمه فارسی» که جداگانه استریم می‌شود.
  - کتاب‌های مشابه در Carousel، به‌همراه Breadcrumb، Open Graph و «بازگشت به نتایج».
- **درباره (`/about`)**: معرفی سرورق، جمله‌ای از رنه دکارت درباره خواندن (با متن اصلی فرانسوی و منبع)، تصویر انتزاعی SVG از کتاب که با تم روشن و تاریک هماهنگ است، و ایمیل تماس با سازنده.
- **منوی «دسته‌بندی»** بین «خانه» و «کشف کتاب‌ها»:
  - در دسکتاپ با Hover (و کلیک یا صفحه‌کلید) باز می‌شود و ۱۶ موضوع را با آیکون و توضیح نشان می‌دهد.
  - در عرض کمتر از ۱۰۲۴ پیکسل پنل تمام‌عرض زیر هدر باز می‌شود.
  - در موبایل بخش بازشونده داخل منوی کناری است.
- **متن‌های چندخطی فارسی** مثل Word تراز دوطرفه (justify) هستند. متن‌های تک‌خطی، بخش‌های وسط‌چین و نقل‌قول درشت صفحه درباره از این قاعده مستثنا هستند.
- **علاقه‌مندی‌ها (`/favorites`)**: ذخیره در localStorage (همراه عنوان فارسی)، مرتب‌سازی، بازگردانی پس از حذف و Dialog حذف همه.
- **سایر**:
  - تم روشن و تاریک، صفحه ۴۰۴ و خطای اختصاصی.
  - وضعیت‌های Loading (Shimmer)، Empty و Error در همه بخش‌ها.
  - `prefers-reduced-motion` و دسترس‌پذیری صفحه‌کلید.

## فونت

متن فارسی با **B Nazanin** نمایش داده می‌شود (`app/fonts/BNazanin*.woff2`):

- با `unicode-range` فقط روی حروف فارسی و عربی اعمال می‌شود؛ متن لاتین با Vazirmatn و Newsreader نمایش داده می‌شود.
- با `size-adjust: 118%` بزرگ‌تر شده، چون B Nazanin در اندازه اسمی یکسان کوچک‌تر دیده می‌شود.

> **مجوز:** B Nazanin متعلق به برنا رایانه است، به‌صورت رایگان توزیع می‌شود اما مجوز متن‌باز ندارد. فایل‌ها از نسخه نصب‌شده روی سیستم توسعه‌دهنده تبدیل شده‌اند (`app/fonts/NOTICE-b-nazanin.txt`). پیش از انتشار عمومی، شرایط استفاده را از صاحب اثر بررسی کنید.

## ترجمه فارسی

ترجمه فقط سمت سرور انجام می‌شود و به این ترتیب پیش می‌رود:

1. متنی که از قبل فارسی است دست نمی‌خورد.
2. **واژه‌نامه گزیده** (`lib/translate/glossary.ts`): عنوان نسخه‌های فارسیِ منتشرشده کتاب‌های شناخته‌شده (مثل Dune → «تلماسه»)، نگارش رایج نام نویسندگان و موضوعات پرکاربرد.
3. **کش** در حافظه و روی دیسک (`node_modules/.cache/sarvaragh/translations.json`).
4. **ترجمه ماشینی**، به ترتیب. هر سرویس فقط مواردی را ترجمه می‌کند که سرویس قبلی ترجمه نکرده است:
   1. **Claude** (`claude-opus-5-5`)، فقط اگر `ANTHROPIC_API_KEY` تنظیم شده باشد. کیفیت بهتری دارد و عنوان‌های منتشرشده فارسی را می‌شناسد.
   2. **Google Translate** (رایگان، بدون کلید):
      - همه عنوان‌های یک صفحه در یک یا چند درخواست دسته‌ای ترجمه می‌شوند (هر درخواست تا ۴۰ مورد).
      - اگر Google درخواست‌ها را رد کند، ۱۰ دقیقه کنار گذاشته می‌شود.
   3. **MyMemory**، به‌عنوان پشتیبان.

ترجمه‌ها مهلت زمانی دارند. اگر ترجمه به‌موقع نرسد:
- متن اصلی نمایش داده می‌شود و ترجمه در پس‌زمینه ادامه پیدا می‌کند.
- صفحه کشف چند ثانیه بعد خودکار دوباره درخواست می‌دهد (حداکثر ۳ بار) و عنوان‌های فارسی جایگزین می‌شوند.
- ترجمه‌ها برای بازدیدهای بعدی کش می‌شوند.

معرفی کتاب با برچسب «ترجمه خودکار» نمایش داده می‌شود و متن اصلی همیشه در دسترس است.

## پیش‌نیازها

- Node.js نسخه ۲۰٫۹ یا بالاتر (با Node 24 تست شده)
- دسترسی سرور (نه مرورگر) به اینترنت:
  - ضروری: `openlibrary.org`
  - برای ترجمه: `clients5.google.com` یا `api.mymemory.translated.net`
  - برای جلدها: `covers.openlibrary.org`، `wsrv.nl` یا `books.google.com`، دست‌کم یکی از این‌ها

کتاب‌های صفحه اصلی بر اساس آمار Open Library به‌مرور عوض می‌شوند. جلد کتاب‌های تازه از پروکسی می‌آید، ولی برای اینکه همه جلدها دوباره محلی شوند، پیش از build دستور `npm run covers:home` را اجرا کنید. این دستور فقط جلدها و عکس‌های جدید را دانلود می‌کند و فهرست‌های `lib/home-covers.json` و `lib/home-authors.json` را به‌روز می‌کند.

متغیرهای محیطی همه اختیاری‌اند (نمونه در `.env.example`):

| متغیر | کاربرد |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | دامنه نهایی، برای URL مطلق Open Graph |
| `ANTHROPIC_API_KEY` | فعال‌سازی ترجمه با Claude (هزینه‌بر طبق تعرفه Anthropic) |
| `MYMEMORY_EMAIL` | ایمیل خودتان برای افزایش سهمیه رایگان MyMemory از حدود ۵٬۰۰۰ به ۵۰٬۰۰۰ نویسه در روز |
| `TRANSLATION_CACHE_FILE` | مسیر دلخواه فایل کش ترجمه |
| `SARVARAGH_CACHE_DIR` | مسیر دلخواه کش دیسکی پاسخ‌ها و جلدها |

## معماری داده

```
مرورگر ─► /api/search ─► searchBooks()  [use cache]
                           ├─ ترجمه کوئری فارسی به انگلیسی
                           ├─ searchRaw() ─► openlibrary.org/search.json  [use cache]
                           └─ localizeSummaries()  واژه‌نامه ← کش ← Claude/Google/MyMemory

صفحه کتاب ─► getBookDetail()        عنوان، نویسنده، موضوع (سریع)
          ─► getBookDescriptionFa() معرفی ترجمه‌شده (استریم جداگانه)
          ─► getSimilarBooks()

مرورگر ─► /covers/{id}.jpg              جلدهای صفحه اصلی (فایل ثابت)
       ─► /api/cover/{workId}?c=&e=&s=  ─► حافظه ← دیسک ← Open Library ← wsrv.nl ← Google Books (ISBN)
       ─► /api/author-photo/{id}        ─► حافظه ← دیسک ← Open Library
```

- **محبوبیت واقعی:** «محبوب‌ترین» یعنی تعداد کاربران Open Library که کتاب را در فهرست مطالعه گذاشته‌اند (`readinglog`). «بالاترین امتیاز» میانگین رأی کاربران است و فقط کتاب‌هایی با دست‌کم ۲۰ رأی را در بر می‌گیرد.
- **موضوع دقیق:** فیلتر موضوع با `subject_key` کار می‌کند تا مثلاً «علوم» شامل «علمی‌تخیلی» نشود.
- **مدارا با سرویس عمومی:**
  - حداکثر ۶ درخواست هم‌زمان به Open Library و ۶ درخواست به MyMemory.
  - درخواست‌های یکسان هم‌زمان یک بار ارسال می‌شوند.
  - یک تلاش مجدد با رعایت `Retry-After` برای 429، 5xx و خطای شبکه.
- **کش:**
  - پاسخ‌های Open Library تا ۶ ساعت و جلدها برای همیشه روی دیسک کش می‌شوند و پس از راه‌اندازی دوباره سرور هم باقی می‌مانند.
  - خطاها فقط چند ثانیه و ترجمه‌های ناقص کوتاه‌مدت کش می‌شوند تا قطعی موقت ماندگار نشود.
- **جلدها:**
  - مرورگر هیچ‌وقت مستقیم به `covers.openlibrary.org` وصل نمی‌شود. همه جلدها از همین دامنه می‌آیند: فایل محلی یا پروکسی `/api/cover`.
  - پروکسی ابتدا Open Library را مستقیم امتحان می‌کند (مهلت ۸ ثانیه، چون هر جلد از دو redirect می‌گذرد و ۱ تا ۵ ثانیه طول می‌کشد).
  - اگر نرسید، همان تصویر را از [wsrv.nl](https://wsrv.nl) می‌گیرد؛ یک کش تصویر عمومی که Open Library را از سرورهای خودش می‌خواند. پس از ۳ شکست پیاپی، مسیر مستقیم ۵ دقیقه کنار گذاشته می‌شود.
  - اگر Open Library جلدی نداشت، جلد با ISBN همان ویرایش از Google Books گرفته می‌شود. تصاویر «جلد موجود نیست» Google کنار گذاشته می‌شوند.
  - «جلد ندارد» فقط وقتی ۶ ساعت به خاطر سپرده می‌شود که همه منابع واقعاً جواب منفی داده باشند. خطای شبکه فقط ۲ دقیقه در حافظه می‌ماند و پاسخ آن (`503`) در مرورگر کش نمی‌شود.
  - پاسخ پروکسی با `Cache-Control: immutable` یک سال در مرورگر می‌ماند.
  - loader سفارشی `next/image` بین اندازه‌های M و L انتخاب می‌کند.
  - تا رسیدن تصویر Shimmer نمایش داده می‌شود و تصویر با Fade ظاهر می‌شود.
  - اگر جلد ۸ ثانیه پس از دیده شدن نرسد، جلد جایگزین طراحی‌شده با عنوان فارسی نمایش داده می‌شود.
- **امنیت:**
  - متن جستجو از نحو Solr پاک می‌شود و شناسه‌ها اعتبارسنجی می‌شوند.
  - توضیحات فقط به‌صورت متن ساده و بدون `dangerouslySetInnerHTML` نمایش داده می‌شوند.
  - کلید API فقط سمت سرور خوانده می‌شود.

## طراحی و انیمیشن

- **پالت Editorial:** کرم، سبز تیره، طلایی و زرشکی، به‌صورت CSS Variable با نسخه تاریک.
- **کارت کتاب:** بالا آمدن حدود ۴ پیکسل، بزرگ شدن جلد و نوار نور براق روی جلد. نشان امتیاز روی جلد، عنوان فارسی و عنوان اصلی زیر آن.
- **دیوار جلد:** سه ستون با حرکت آرام عمودی در همه اندازه‌های صفحه (در موبایل کوچک‌تر). با Hover متوقف می‌شود و با `prefers-reduced-motion` ثابت می‌ماند.
- **انیمیشن‌های Hover در موبایل:** صفحه‌های لمسی Hover ندارند. کارت‌ها (کتاب، موضوع، نویسنده و جلد سه‌بعدی صفحه کتاب) وقتی هنگام اسکرول از میانه صفحه می‌گذرند همان انیمیشن Hover دسکتاپ را اجرا می‌کنند، و دکمه‌ها هنگام لمس. پیاده‌سازی: variant سفارشی `hover` در `app/globals.css` و `components/motion/touch-hover.tsx`.
- **ورود محتوا:** Fade-up کارت‌ها با تأخیر پلکانی کوتاه، و ظاهر شدن بخش‌ها هنگام اسکرول (Reveal).
- **تعامل‌ها:** شمارنده متحرک تعداد نتایج، انفجار ذرات روی دکمه قلب و Toast.
- **جابه‌جایی صفحه‌ها:** View Transitions، شامل جابه‌جایی جلد از کارت به صفحه کتاب.
- **پنل‌ها:** Dialog و Sheet ۲۰۰ تا ۳۰۰ میلی‌ثانیه؛ تغییر تم با گذار رنگی کنترل‌شده.

## عیب‌یابی: چرا تصاویر لود نمی‌شدند و ترجمه کار نمی‌کرد

- **تصاویر:**
  - روی بعضی شبکه‌ها `covers.openlibrary.org` و `archive.org` فیلتر هستند (با SNI). اتصال برقرار می‌شود ولی TLS هیچ‌وقت کامل نمی‌شود.
  - برای همین مرورگر روی هر جلد تا زمان timeout معطل می‌ماند. ده‌ها اتصال معلق، بارگذاری بقیه صفحه را هم کند می‌کرد.
  - راه‌حل: جلدها از پروکسی سرور می‌آیند، و جلدهای صفحه اصلی به‌صورت فایل محلی همراه پروژه هستند.
  - اشکال دوم پروکسی: مهلت ۴ ثانیه‌ای برای Open Library کوتاه بود (هر جلد ۱ تا ۵ ثانیه، گاهی بیشتر). پس از اولین timeout، Open Library ۱۰ دقیقه کنار گذاشته می‌شد و نبودِ جلد ۶ ساعت به خاطر سپرده می‌شد؛ نتیجه، پیام «جلد در دسترس نیست» برای کتاب‌هایی بود که جلد داشتند. با مهلت بیشتر، مسیر جایگزین wsrv.nl و تفکیک خطای شبکه از نبودِ جلد برطرف شد.
- **ترجمه:**
  - تنها مترجم رایگان MyMemory بود و سهمیه روزانه ۵٬۰۰۰ نویسه‌ای آن خیلی زود تمام می‌شد. بعد از آن همه متن‌ها انگلیسی می‌ماندند.
  - راه‌حل: Google Translate با درخواست‌های دسته‌ای مترجم اصلی شد. MyMemory فقط پشتیبان است.
- **کندی:**
  - اتصال‌های معلق جلدها (برطرف شد).
  - تأخیر Open Library در اولین درخواست. با کش دیسکی، فیلدهای سبک‌تر برای فهرست‌ها و سقف هم‌زمانی کاهش یافت.
  - در حالت `npm run dev` هر صفحه بار اول کامپایل می‌شود. برای سنجش سرعت واقعی از `npm run build && npm start` استفاده کنید.

## محدودیت‌های شناخته‌شده

- **وابستگی به سرویس‌های عمومی:**
  - Open Library گاهی کند است (برای موضوعات بزرگ ۳ تا ۸ ثانیه در اولین درخواست، سپس از کش) یا در دسترس نیست.
  - اولین بار که جلد یک کتاب درخواست می‌شود ۱ تا ۷ ثانیه طول می‌کشد. پس از آن از کش و تقریباً فوری نمایش داده می‌شود.
  - در زمان قطعی، پیام خطا و «تلاش دوباره» نمایش داده می‌شود.
- **Google Translate:**
  - از نقطه دسترسی رایگان و غیررسمی افزونه مرورگر Google استفاده شده و هیچ تضمینی برای پایداری آن نیست.
  - اگر از کار بیفتد، ترجمه به MyMemory برمی‌گردد که سهمیه روزانه محدودی دارد. ترجمه‌های قبلی در کش می‌مانند.
  - برای ترجمه پایدار و باکیفیت‌تر `ANTHROPIC_API_KEY` را تنظیم کنید.
- **wsrv.nl:** سرویسی رایگان و عمومی است و تضمینی برای پایداری آن نیست. اگر هم Open Library و هم wsrv.nl در دسترس نباشند، کتاب‌های خارج از صفحه اصلی جلد طراحی‌شده می‌گیرند.
- **جلدهای Google Books** (فقط وقتی Open Library جلد ندارد) با ISBN پیدا می‌شوند. گاهی جلد ویرایشی به زبان دیگر نمایش داده می‌شود.
- **فیلتر «فقط کتاب‌های دارای جلد»** پیش‌فرض است، پس کتابی که در Open Library جلد ندارد در جستجو و Ctrl+K دیده نمی‌شود مگر اینکه فیلتر خاموش شود.
- **عکس نویسندگان** در صفحه اصلی محلی است. در صفحه کتاب از Open Library (مستقیم یا wsrv.nl) می‌آید و اگر در دسترس نباشد، حروف اول نام نمایش داده می‌شود.
- **کیفیت ترجمه:** ترجمه ماشینی برای عنوان‌های کم‌شناخته ممکن است با نام نسخه منتشرشده فارسی فرق کند. عنوان اصلی همیشه کنار ترجمه نمایش داده می‌شود.
- **ترجمه با Claude:** این مسیر پیاده‌سازی و از نظر نوع‌ها بررسی شده، اما بدون کلید API به‌صورت واقعی اجرا نشده است.
- **مرتب‌سازی الفبایی** فقط روی همان صفحه نتایج انجام می‌شود، چون API ترتیب نزولی عنوان ندارد.
- **فیلتر زبان** یعنی «دست‌کم یک ویرایش به این زبان».
- **علاقه‌مندی‌ها** فقط در همان مرورگر ذخیره می‌شوند.
- **کد وضعیت HTTP:** شناسه کتابی که قالب درستی دارد ولی وجود ندارد، صفحه ۴۰۴ را نشان می‌دهد اما به‌دلیل استریم شدن صفحه، کد HTTP آن ۲۰۰ است.

## Deploy

**Vercel:** پروژه را از GitHub وارد کنید یا با `npx vercel login` و سپس `npx vercel deploy --prod` مستقیم منتشر کنید. هیچ متغیر محیطی‌ای الزامی نیست؛ `metadataBase` بدون `NEXT_PUBLIC_SITE_URL` از دامنه production خود Vercel استفاده می‌کند. روی محیط Serverless، کش دیسکی (ترجمه، پاسخ‌ها و جلدها) غیرفعال می‌شود و فقط کش حافظه، `use cache` و کش مرورگر و CDN برای جلدها کار می‌کنند. برای ترجمه پایدار، `ANTHROPIC_API_KEY` توصیه می‌شود.

میزبانی شخصی: `npm run build && npm start` روی Node 20.9 یا بالاتر. در این حالت کش‌ها روی دیسک ماندگارند. مسیر کش را می‌توانید با `SARVARAGH_CACHE_DIR` تغییر دهید.
